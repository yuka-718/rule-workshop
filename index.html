          A LITTLE RUBY, A LOT OF POSSIBILITIES
          
    ルールの書き方、はじめの一歩。
    
          
    
            rule の中に、盤面
            b が満たす条件をひとつ。
    すべての条件が
            true になる盤面が、答えです。
          
    
        
    
        
    
          
    
            01 / 数えるb.count(:red) == 3
            
    赤いマスを、ちょうど3つに。
    
          
    
          
    
            02 / 場所を決めるb.cell(2, 2) == :red
            
    2行2列、まんなかを赤に。
    
          
    
          
    
            03 / 関係をつくる!b.adjacent?(:red)
            
    赤どうしは上下左右にくっつけない。
    
          
    
        
    
        
    
          使える構文と制約をすべて見る ＋
          
    
            
    
              3×3・赤と青の2色専用です。座標は1始まり（1〜3）。未入力のマスはプレイ中だけの状態です。
            
    
            
    
              
    
                
                  
    
                    書き方
                    調べられること
                  
    
                    
                
                  
    
                    b.count(:red)
                    盤面全体の赤の数
                  
    
                  
    
                    b.cell(1, 2)
                    1行2列の色
                  
    
                  
    
                    b.row_count(1, :red)
                    1行目の赤の数
                  
    
                  
    
                    b.col_count(2, :blue)
                    2列目の青の数
                  
    
                  
    
                    b.adjacent?(:red)
                    赤が上下左右に隣接するか（斜めは含まない）
                  
    
                    
              
    
            
    
            
    
              :red / :blue、整数0〜9、true
              / false、比較
              == != < <= > >=、論理
              && || !、括弧が使えます。メソッドの引数には数値・色を直接書きます。
            
    
            
    
              通常のRubyを自由に実行する環境ではありません。変数代入、ループ、定義、定数参照、文字列の式展開、任意のメソッド呼び出しは使えません。最大8,192バイト・24ルール・構文木の深さ64・2,048ノード。計算の上限は8秒です。
            
    
            
    
              生成時は一意解を保ちながらヒントを外します。ヒント数が最少になる保証はありません。データはこのブラウザに保存され、共有URLにはルールとヒントのみを含めます。
