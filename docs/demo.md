# 約3分の実演

1. サイトを開く。初回はRubyの読み込みを待つ。初期サンプル「赤を3つ、くっつけずに」はRubyが512通りを調べ、22通りと表示する。
2. コードの `b.count(:red) == 3` を `b.count(:red) == 2` に書き換える。「変更前の結果」に変わり、「問題を作る」が押せなくなることを見せる。
3. 「ルールを調べる」を押す。解の数は24通りになる。数値は実際のRuby計算結果。
4. 「問題を作る」を押す。ルールだけの解数と、ヒント込みの解数1通りが別々に表示される。
5. 固定ヒント以外のマスをクリック、またはR / Bで入力する。未入力の間は入力中、入力完了後にRubyが判定する。誤答なら満たしていないルールを赤い文字で表示。正答なら控えめに盤面が動き、クリアメッセージが出る。
6. 「共有」を押してURLをコピーし、別のブラウザまたはプライベートウィンドウで開く。ルール内容を確認して読み込みボタンを押し、同じ固定ヒントから遊べることを確認する。
7. 「サンプルを選ぶ」から「あれ？ 解がない」を選んで検証。解0通りで生成できないことを確認。矛盾を直せば問題にできる。

## 発表で説明するポイント

- 512通りに絞ることで、解の数を推測でなく正確に数えられる。
- Rubyは構文解析、データモデル、条件判定、全探索、問題生成、解答判定を担当する。
- 独自DSLを読む仕組みで、入力文字列をそのまま実行していない。
- ヒント除去は一意解を確認しながら行う。「最少ヒント」とは説明しない。
- サーバー不要で、作った問題をURLだけで渡せる。正解そのものは共有URLに入れない。
